# گردونه شانس وب‌تنان

**Webtanan Lucky Wheel** افزونه فارسی وردپرس برای اجرای گردونه شانس، کمپین فروش، کد تخفیف ووکامرس و ثبت شرکت‌کنندگان با شماره موبایل است. نتیجه گردونه و تعداد شانس‌ها سمت سرور کنترل می‌شوند.

## امکانات نسخه 1.3.0

- فارسی و RTL کامل.
- شرکت در قرعه‌کشی **بدون ساخت حساب وردپرس**.
- ورودی کاربر فقط: **نام و نام خانوادگی + شماره موبایل**.
- هر شماره موبایل یک شرکت‌کننده یکتا است و ورود مجدد، شانس‌ها را از ابتدا شارژ نمی‌کند.
- نگهداری نشست امن در مرورگر برای ادامه فرآیند بعد از رفرش صفحه.
- پشتیبانی از شماره‌های ایران با ارقام فارسی، عربی و لاتین.
- گردونه عادی داخل صفحه یا پاپ‌آپ.
- پاپ‌آپ با دکمه، بازشدن خودکار، تأخیر قابل تنظیم، بستن با پس‌زمینه یا Esc.
- کد تخفیف یک‌بارمصرف ووکامرس برای شرکت‌کننده مهمان.
- شانس اضافه و اعتبار جایزه بدون نیاز به حساب کاربری.
- تاریخچه مدیریت با نام، شماره موبایل، جایزه، کد تخفیف، شانس و اعتبار.
- تنظیم رنگ قالب از پنل مدیریت بدون ویرایش CSS.
- پالت پیش‌فرض نسخه 1.3 برای فروشگاه **Altin Watch**: مشکی/زغالی + طلایی شامپاینی.
- رنگ هر قطعه گردونه همچنان به‌صورت جداگانه در مدیریت جوایز قابل تنظیم است.

## نصب

1. پوشه افزونه را در `wp-content/plugins/` قرار دهید یا ZIP را از مدیریت وردپرس نصب کنید.
2. افزونه **گردونه شانس وب‌تنان** را فعال کنید.
3. از **گردونه شانس ← تنظیمات گردونه** جوایز و احتمال‌ها را تنظیم کنید.
4. از **گردونه شانس ← ظاهر و رنگ‌بندی** رنگ‌های قالب را تنظیم کنید.

## شورت‌کدها

نمایش معمولی:

```text
[webtanan_lucky_wheel]
```

نمایش پاپ‌آپ:

```text
[webtanan_lucky_wheel popup="1"]
```

متن دلخواه دکمه:

```text
[webtanan_lucky_wheel popup="1" button_text="شانس خودت را امتحان کن"]
```

بازشدن خودکار بعد از ۲ ثانیه:

```text
[webtanan_lucky_wheel popup="1" auto_open="1" delay="2000"]
```

## شرکت‌کننده بدون ثبت‌نام

نسخه 1.3 دیگر برای شرکت‌کننده حساب WordPress ایجاد نمی‌کند. پس از وارد کردن نام و موبایل، یک رکورد امن در جدول اختصاصی شرکت‌کنندگان ساخته یا بازیابی می‌شود. شماره موبایل یکتا است؛ بنابراین کاربر با ورود مجدد همان شانس باقی‌مانده قبلی را می‌بیند.

اطلاعات شرکت‌کنندگان در جدول `wp_webtanan_wheel_participants` و نتایج گردونه در `wp_webtanan_wheel_logs` نگهداری می‌شوند. پیشوند جدول مطابق تنظیمات وردپرس سایت تغییر می‌کند.

## ووکامرس

اگر ووکامرس فعال باشد، جایزه‌های Coupon برای شرکت‌کنندگان مهمان به‌صورت کد تخفیف یک‌بارمصرف ساخته می‌شوند. چون کاربر حساب و ایمیل ندارد، کوپن به حساب کاربری محدود نمی‌شود اما سقف استفاده آن یک بار است و به شناسه داخلی شرکت‌کننده متصل می‌شود.

در نبود ووکامرس، اعتبار جایزه روی رکورد همان شماره موبایل ذخیره می‌شود.

## ظاهر و رنگ‌بندی

در منوی **ظاهر و رنگ‌بندی** می‌توان موارد زیر را تغییر داد:

- رنگ اصلی
- رنگ دوم
- رنگ تأکیدی / طلایی
- پس‌زمینه
- سطح کارت و فرم
- رنگ متن اصلی
- رنگ متن فرعی

دکمه **بازگشت به پالت پیشنهادی آلتین واچ** ترکیب مشکی زغالی و طلایی شامپاینی را برمی‌گرداند.

## امنیت

- WordPress nonce برای AJAX
- توکن تصادفی و هش‌شده برای نشست شرکت‌کننده
- محدودیت درخواست بر اساس IP
- جلوگیری از پردازش دوباره درخواست چرخش
- قفل کوتاه‌مدت برای جلوگیری از چرخش هم‌زمان
- انتخاب وزنی جایزه در PHP با `random_int`
