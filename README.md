## معرفی

**گردونه شانس وب‌تنان** برای اجرای کمپین‌های فروش و باشگاه مشتریان در وردپرس ساخته شده است. انتخاب جایزه، تعداد شانس و ثبت نتیجه در سمت سرور کنترل می‌شود و مرورگر فقط انیمیشن نتیجه قطعی را نمایش می‌دهد.

کاربر مهمان فقط **نام و شماره موبایل** را وارد می‌کند. اگر کاربر از قبل در وردپرس لاگین باشد، فرم شرکت در قرعه‌کشی نمایش داده نمی‌شود و کاربر مستقیم وارد گردونه می‌شود.

## 🧭 روند کاربر

### کاربر مهمان

```text
باز شدن صفحه
   ↓
نام + شماره موبایل
   ↓
بازیابی/ساخت شرکت‌کننده
   ↓
گردونه
   ↓
جایزه
   ↓
در صورت کوپن: ساخت کد تخفیف + ارسال پیامک
```

### کاربر لاگین‌شده

```text
باز شدن صفحه
   ↓
تشخیص خودکار حساب وردپرس
   ↓
بدون فرم
   ↓
گردونه
```

## 🚀 نصب

1. افزونه را در `wp-content/plugins/` قرار دهید یا ZIP آن را از مدیریت وردپرس نصب کنید.
2. افزونه **گردونه شانس وب‌تنان** را فعال کنید.
3. از **گردونه شانس ← تنظیمات گردونه** عنوان، تعداد شانس و وضعیت کمپین را تنظیم کنید.
4. از **گردونه شانس ← مدیریت جوایز** جایزه‌ها، احتمال‌ها، رنگ‌ها و تاریخ انقضای کوپن را تنظیم کنید.
5. از **گردونه شانس ← ظاهر و رنگ‌بندی** رنگ قالب را تنظیم کنید.
6. در صورت نیاز به پیامک، بخش **گردونه شانس ← پیامک IPPanel** را تکمیل کنید.

## 🔄 ریست روزانه شانس

افزونه تاریخ آخرین ریست را با زمان محلی وردپرس نگهداری می‌کند.

در شروع روز جدید:

- شرکت‌کننده‌های مهمانی که `remaining_attempts <= 0` دارند به تعداد شانس پیش‌فرض برمی‌گردند.
- کاربران وردپرسی لاگین‌شده که شانسشان صفر شده نیز ریست می‌شوند.
- کاربری که هنوز شانس دارد دست‌کاری نمی‌شود.
- پاپ‌آپ برای کاربر صفرشانس در همان روز مخفی می‌ماند و روز بعد پس از ریست دوباره قابل نمایش است.

علاوه بر WP-Cron، کنترل تاریخ روی `init` نیز انجام می‌شود تا حتی اگر Cron دقیقاً نیمه‌شب اجرا نشود، اولین بازدید روز جدید ریست را انجام دهد.

## 📲 IPPanel Edge API

پیاده‌سازی پیامک بر مبنای مستندات IPPanel Edge است:

- Base URL پیش‌فرض: `https://edge.ippanel.com/v1`
- Endpoint ارسال پترن: `POST /api/send`
- هدر احراز هویت: `Authorization`
- نوع ارسال: `sending_type = pattern`
- شماره گیرنده: E.164 مانند `+989121234567`

مستندات:

- https://docs.ippanel.com/docs/
- https://ippanelcom.github.io/Edge-Document/fa/docs/send/pattern/

### تنظیمات مدیریت

از مسیر **گردونه شانس ← پیامک IPPanel** می‌توانید تنظیم کنید:

- فعال/غیرفعال بودن ارسال
- Base URL
- API Key / Token
- شماره ارسال‌کننده
- چند پترن مستقل
- کد پترن
- پترن فعال
- متن مدیریت‌شده
- نام پارامترهای پترن

### متغیرهای متن مدیریت

```text
{name}    نام کاربر
{coupon}  کد تخفیف
{expiry}  تاریخ انقضا شمسی
{reward}  عنوان جایزه
```

نمونه متن:

```text
تبریک {name}، کد تخفیف شما {coupon} است و تا {expiry} اعتبار دارد.
```

پارامترهای استاندارد ارسالی به پترن نیز قابل تغییرند و به‌صورت پیش‌فرض عبارت‌اند از:

```text
name
code
expiry
reward
message
```

بنابراین پترن IPPanel می‌تواند از پارامترهای جداگانه یا از یک پارامتر `message` برای متن کامل استفاده کند.

## 🎡 نوشته‌های گردونه

متن هر جایزه در امتداد محور مرکزی همان سگمنت قرار می‌گیرد. برای نیمه پایین گردونه متن ۱۸۰ درجه برگردانده می‌شود تا همچنان خوانا باشد، اما امتداد آن با همان خانه حفظ شود.

مرزهای رنگی واقعی سگمنت‌ها مبنای نمایش هستند و خطوط تزئینی ساختگی روی گردونه استفاده نمی‌شود.
