## معرفی

**گردونه شانس وب‌تنان** برای اجرای کمپین‌های فروش، جذب لید و باشگاه مشتریان در وردپرس طراحی شده است. انتخاب جایزه، کنترل تعداد شانس، ثبت نتیجه و ساخت کوپن در سمت سرور انجام می‌شود و رابط کاربری فقط نتیجه معتبر سرور را نمایش می‌دهد.

کاربر مهمان فقط **نام و شماره موبایل** را وارد می‌کند. اگر کاربر از قبل در WordPress لاگین باشد، فرم حذف می‌شود و کاربر مستقیم به گردونه می‌رود.

نسخه `1.5.0` تمرکز ویژه‌ای روی **سرعت ادراکی، واکنش آنی رابط، ساختار بارگذاری اصولی وردپرس و شخصی‌سازی رابط** دارد.

## ⚡ معماری و کارایی

نسخه 1.5 به‌جای بارگذاری همه کلاس‌های رابط در تمام درخواست‌ها، فایل‌ها را متناسب با Context بارگذاری می‌کند:

- درخواست AJAX: کنترلر AJAX
- مدیریت WordPress: صفحات مدیریت و تنظیمات
- Front-end: شورت‌کد و دارایی‌های عمومی
- Cron: فقط سرویس‌های موردنیاز پردازش زمینه‌ای

CSS و JavaScript عمومی نیز فقط زمانی Enqueue می‌شوند که شورت‌کد گردونه واقعاً Render شود.

ارسال پیامک خارجی در مسیر اصلی چرخش انجام نمی‌شود؛ اگر WooCommerce Action Scheduler موجود باشد، پیامک به صف آن سپرده می‌شود و در غیر این صورت WP-Cron به‌عنوان Fallback استفاده می‌شود. این کار مانع اثرگذاری تأخیر سرویس پیامکی روی پاسخ گردونه می‌شود.

## 🧭 تجربه کاربر

### کاربر مهمان

```text
باز شدن کمپین
   ↓
نام + شماره موبایل
   ↓
نمایش فوری مرحله گردونه
   ↓
تأیید امن اطلاعات در سرور
   ↓
کلیک روی چرخش
   ↓
شروع فوری انیمیشن + کاهش لحظه‌ای شانس
   ↓
دریافت نتیجه قطعی سرور
   ↓
توقف در مرکز جایزه + تطبیق تعداد شانس
```

### کاربر لاگین‌شده

```text
باز شدن کمپین
   ↓
تشخیص خودکار حساب WordPress
   ↓
بدون فرم
   ↓
نمایش مستقیم گردونه و تعداد شانس
```

## 🎛 تنظیم متن دکمه‌ها و لوگوی مرکز

از مسیر زیر:

**گردونه شانس ← رابط و دکمه‌ها**

موارد زیر قابل مدیریت هستند:

- متن دکمه بازکردن پاپ‌آپ
- متن دکمه شرکت در قرعه‌کشی
- متن دکمه چرخاندن گردونه
- متن دکمه تأیید نتیجه
- تصویر مرکز گردونه

لوگو از **Media Library وردپرس** انتخاب و با شناسه Attachment ذخیره می‌شود. در Front-end تصویر به‌صورت دایره‌ای و با `object-fit: cover` داخل مرکز گردونه قرار می‌گیرد. اگر تصویری انتخاب نشده باشد، متن «شانس» نمایش داده می‌شود.

پارامتر `button_text` در شورت‌کد همچنان می‌تواند متن دکمه پاپ‌آپ همان نمونه را Override کند.

## 🚀 نصب

1. افزونه را در `wp-content/plugins/` قرار دهید یا ZIP آن را از مدیریت WordPress نصب کنید.
2. افزونه **گردونه شانس وب‌تنان** را فعال کنید.
3. از **گردونه شانس ← تنظیمات گردونه** عنوان، تعداد شانس و وضعیت کمپین را تنظیم کنید.
4. از **گردونه شانس ← مدیریت جوایز** جایزه‌ها، احتمال‌ها و تاریخ انقضا را تنظیم کنید.
5. از **گردونه شانس ← ظاهر و رنگ‌بندی** رنگ‌ها را تنظیم کنید.
6. از **گردونه شانس ← رابط و دکمه‌ها** متن‌ها و لوگوی مرکز را تنظیم کنید.
7. در صورت نیاز، **گردونه شانس ← پیامک IPPanel** را تکمیل کنید.

## 🔄 ریست روزانه شانس

در شروع روز جدید:

- مهمان‌هایی که `remaining_attempts <= 0` دارند به تعداد شانس پیش‌فرض برمی‌گردند.
- کاربران WordPress که شانسشان صفر شده نیز ریست می‌شوند.
- کاربری که هنوز شانس دارد دست‌کاری نمی‌شود.
- پاپ‌آپ برای صفرشانس‌ها در همان روز مخفی می‌ماند.

WP-Cron و کنترل اولین درخواست روز جدید هر دو برای حفظ این رفتار استفاده می‌شوند.

## 📲 IPPanel Edge API

تنظیمات پیامک از مسیر **گردونه شانس ← پیامک IPPanel** در دسترس است.

امکانات:

- Base URL
- API Key / Token
- شماره ارسال‌کننده
- چند پترن مستقل
- انتخاب پترن فعال
- کد پترن
- نام پارامترها
- متن قابل مدیریت

متغیرهای متن:

```text
{name}    نام کاربر
{coupon}  کد تخفیف
{expiry}  تاریخ انقضا شمسی
{reward}  عنوان جایزه
```

ارسال جایزه در نسخه 1.5 به‌صورت **Queue/Background** انجام می‌شود تا سرویس خارجی IPPanel سرعت تجربه چرخش را کاهش ندهد.

## 🎡 جهت متن و توقف گردونه

نتیجه در PHP انتخاب می‌شود. پس از دریافت مقصد واقعی، JavaScript زاویه نهایی را محاسبه می‌کند و پیش از توقف، جهت خوانایی هر نوشته را برای موقعیت نهایی مشخص می‌کند. بنابراین Flip صدوهشتاددرجه در لحظه توقف آماده است و بعد از پایان انیمیشن با تأخیر اعمال نمی‌شود.

نمایشگر سپس دقیقاً به مرکز سگمنت انتخاب‌شده می‌رسد.

## 🔐 امنیت

کنترل‌های امنیتی اصلی:

- WordPress Nonce برای درخواست‌های AJAX
- `manage_options` و Nonce برای تنظیمات مدیریت
- Sanitization و Validation ورودی‌ها
- Rate Limit بر اساس IP
- شناسه یکتای درخواست برای جلوگیری از Replay
- Lock کوتاه‌مدت برای جلوگیری از Double Spin
- کنترل قطعی تعداد شانس در PHP
- انتخاب وزنی با `random_int`
- توکن هش‌شده برای مهمان
- API Key پیامک فقط در سمت سرور
- نتیجه جایزه فقط در سمت سرور تعیین می‌شود

> هیچ نرم‌افزار وب را نمی‌توان به‌صورت مطلق «۱۰۰٪ امن» تضمین کرد؛ هدف این پروژه رعایت اصول WordPress و کاهش سطح حمله با کنترل‌های چندلایه است.
